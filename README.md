# Silicon-Respondent Simulator

Code and analysis for training a fine-tuned LLM as a **"silicon respondent"**: a model conditioned on
a 5-dimensional Big Five latent `(O, C, E, A, N)` that answers personality-questionnaire items so that a
**synthetic population** of such respondents **reproduces human psychometric structure** — factor
congruence (Tucker's φ), inter-factor correlations (Φ), item–total correlations, and Cronbach's α.
Crucially, this structure **holds on held-out items and on a different inventory (BFI)**, enabling
synthetic test authoring. A secondary result is that the model is steerable to "speak" in the voice of a
trait in free text.

This repository accompanies a manuscript targeted at *Behavior Research Methods* (draft in
[`paper/`](paper/)), which contains the full result tables, caveats, and related work.

## Method in brief

A **frozen** backbone (default `Qwen/Qwen2.5-1.5B-Instruct`; also `Llama-3-8B-4bit`) with a frozen LM
head. The Likert answer is read out generatively as a **softmax over the digit tokens "1"–"5"** at the
final position, so the model's language ability is preserved. Trait conditioning uses two paths:

1. **Soft prefix** — a `TraitEncoder` (5→256) projected to 8 trait tokens prepended to the input
   embeddings.
2. **Latent-gated LoRA** — LoRA (r=16, α=32) on the q/k/v/o projections of the last 12 layers, with an
   optional per-rank sigmoid gate driven by the trait code.

A synthetic population is generated by drawing latents `z ~ MVN(0, Σ_human)` and **sampling** (not
argmax) the categorical answer per item, so inter-factor correlations are reproducible.

### Ablation ladder (`--mode`)

| mode         | description                                                        |
|--------------|--------------------------------------------------------------------|
| `baseline_a` | no traits (frozen LM) — floor                                      |
| `baseline_b` | persona described in the prompt text (zero-shot)                   |
| `baseline_c` | trained prefix + LoRA, **no gate**                                 |
| `full`       | trained prefix + **gated** LoRA                                    |

> **Evaluate each checkpoint in the mode it was trained in.** A `baseline_c` checkpoint has an untrained
> gate; running it as `full` activates a random gate and corrupts output.

## Setup

```bash
python -m venv .venv && source .venv/bin/activate   # or conda
pip install -r requirements.txt
```

Psychometrics are computed in **R** (R 4.5.x). Install the R dependencies:

```r
install.packages(c("psych", "GPArotation", "lavaan", "data.table"))
```

R has no `arrow`, so parquet → CSV conversion is done in Python before R is invoked (handled by the
Python drivers). Training was run on a single RTX 4090 (24 GB).

## Data

- **IPIP-50 Big Five** is the training inventory. Build scripts live in [`data/`](data/). The derived
  splits used in the paper are committed as parquet:
  - `data/train.parquet` — 30 items, 15,775 respondents
  - `data/participant_holdout.parquet` — same 30 items, 3,944 new respondents
  - `data/item_holdout.parquet` — **20 held-out items** (the new-items test)
- **BFI (out-of-distribution)** — 25 different items on a 1–6 scale (`data/bfi_items.parquet`,
  `phase_4_bfi/`).
- **Criterion battery** — Grit-S, Rosenberg self-esteem, leadership emergence, procrastination, plus
  Big Five markers (`data/criterion_battery.parquet`, `data/criterion_meta.csv`,
  `data/criterion_literature.csv`), built with `data/build_criterion_battery.py`.

The **raw** IPIP dump (`data.csv`), the full long-format responses (`responses_long.parquet`), model
checkpoints, and all generated silicon/prediction CSVs are **not committed** (size / reproducibility —
see `.gitignore`). The raw IPIP Big Five data is publicly available from
[openpsychometrics.org](https://openpsychometrics.org/_rawdata/). Regenerate the splits with the scripts
in `data/`.

## Quickstart

```bash
# 1. Train the full model (staged, resumable): epoch 1, then resume to 3
python train_simulator.py --mode full --epochs 3 --run_epochs 1
python train_simulator.py --mode full --epochs 3 --run_epochs 0 \
    --resume checkpoints/simulator_full_state.pt

# 2. Generate a silicon sample on held-out IPIP items 
python silicon_sample.py --checkpoint checkpoints/simulator_full.pt \
    --items_file data/item_holdout.parquet --output_file silicon.csv

# 3. Compute psychometrics (Python driver calls the R pipeline)
python 05_simulator_psychometrics.py --human data/item_holdout.parquet --silicon silicon.csv

# BFI out-of-distribution 
python silicon_sample.py --checkpoint checkpoints/simulator_full.pt \
    --items_file data/bfi_items.parquet --temperature 1.0 --output_file silicon_bfi.csv
python 05_simulator_psychometrics.py --human bfi_human_long.csv --silicon silicon_bfi.csv

# Trait intervention (Likert sweep + free-text steering)
python latent_intervention.py --checkpoint checkpoints/simulator_full.pt --task both --trait_idx 2
```

Multi-seed / multi-backbone experiments: `train_campaign.sh` + `eval_campaign.py`. Aggregated tables are
written to [`results/`](results/).

## Key results

- **IPIP held-out (20 new items):** Tucker congruence **0.842** (T=0.6); **0.986** on a well-powered
  30-item test.
- **BFI out-of-distribution (25 never-seen items, different inventory):** congruence **~0.86** —
  cross-inventory transfer.
- **Multi-seed replication:** Qwen (n=4) IPIP Tucker 0.850 ± 0.014, BFI 0.871 ± 0.017; Llama-3-8B-4bit
  (n=4) IPIP 0.873 ± 0.034, BFI 0.843 ± 0.061. The method is not backbone-specific.
- **Criterion validity:** silicon recovers the correct sign on every domain's literature-dominant trait
  (36/36 across checkpoints); mean profile correlation vs. literature ≈ 0.87 — emergent, non-injected
  nomological links.
- **Text steering:** emergent despite digit-only supervision — Llama-3-8B steers all 5 traits cleanly;
  Qwen's instruction-tuning prior masks the effect on most traits.

See [`paper/`](paper/) for full tables, caveats, and the noise ceiling (human split-half) these numbers
are read against.

## Repository layout

```
model/                  Model definitions (RespondentSimulator, gated LoRA, trait encoder, backbones)
data/                   Dataset build scripts + committed parquet splits + criterion battery
paper/                  Manuscript (Markdown + LaTeX), references, figures
results/                Aggregated result tables and summaries (CSV/Markdown)
phase_4_bfi/            BFI inventory responses & dictionary (OOD inventory)

train_simulator.py      Main trainer (soft prefix + gated LoRA; staged/resumable)
silicon_sample.py       Generate a synthetic population from a checkpoint
05_simulator_psychometrics.{py,R}   Psychometrics (Python driver -> R: psych/GPArotation)
06_criterion_validity.py            Criterion-validity analysis
07_partial_betas.py                 Discriminant validity via standardized betas
08_temp_calibration.py              Held-out temperature calibration
09_text_scoring.py                  Score trait-conditioned free-text generations
10_reliability.py                   Silicon test-retest reliability
11_pipeline_validation.py           Human split-half noise ceiling
latent_intervention.py              Trait sweep (Likert) + free-text steering
train_campaign.sh / eval_campaign.py  Multi-seed / multi-backbone campaign driver
aggregate_results.py                Build the mode x test-set result table
```

Numbered scripts without the `_simulator` suffix (`01`–`04`, and the `*_llama*`, `film`, `mlp` files) are
earlier-phase experiments retained for provenance.
